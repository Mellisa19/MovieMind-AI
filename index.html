Settings

MovieMind plays films from the Internet Archive, which needs no key at all. A free TMDB key (themoviedb.org → Settings → API) only upgrades artwork and plot summaries where a confident match exists. Without it, everything still plays.

Optional. MovieMind's search brain runs entirely offline in your browser — it understands genres, moods, decades, “silent”, “short” and titles without any key. Paste a key only if you want a language model to rewrite your request too.
